# austraz.tray

A fork of Omarchy's system tray plugin. Its drawer widgets follow the dock of
[austraz.bar](https://github.com/austrasien/omarchy-bar): when the bar is
docked to the [HUD wallpaper](https://github.com/austrasien/omarchy-hudwall),
a drawer widget's panel opens beside the HUD's bar-icons widget like the
others.
